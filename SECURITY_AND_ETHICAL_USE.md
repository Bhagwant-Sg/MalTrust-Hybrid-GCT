# Security and Ethical Use

MalTrust-Hybrid-GCT is intended for defensive cybersecurity research and academic validation of static Windows PE malware-detection workflows.

## Allowed use

- Defensive malware-detection research.
- Static PE feature-analysis research.
- Reproducibility evaluation.
- Explainability and validation studies.
- Academic comparison under lawful dataset access.
- Controlled cybersecurity education.

## Not allowed or not supported

- Malware generation.
- Malware distribution.
- Malware evasion engineering.
- Bypassing antivirus, EDR, or security controls.
- Unauthorized analysis of systems or users.
- Redistribution of restricted datasets or malware binaries.
- Production blocking decisions without independent validation and security oversight.

## Operational warning

The framework is not claimed to be production-ready. Latency, throughput, endpoint integration, concurrent-request handling, memory footprint, and analyst usability require separate operational benchmarking.
